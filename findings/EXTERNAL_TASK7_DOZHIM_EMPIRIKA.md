## T-D1 cc-эмпирика — SUPPORTED (модель) / SOURCE_CLAIM (эмп.)
**Якорь:** Fagereng et al. 2019 (NBER w26588, административные данные Норвегии): сбережения богатых из капитальных приростов ≈ 100%; FGMP (Econometrica 2020): разброс доходностей 10→90 перц. +18 п.п., персистентность, межгенерационная корреляция.
**Развёртка:** φ=1−cc. Эмпирический φ_top ~0.9–1.0 (по приростам) — тройной запас над порогом φ_min=0.300 (T-F1). Уровни аппарата: A*(φ=0.9)=0.308, A*(0.3)=0.184, A*(0.1)=0.082.
**Вывод:** там, где ренту захватывают верхние классы, петля Debt↔Rent находится в самоподдерживающемся режиме по построению; Meade-порог (1−cc)r>g связывает только средние/нижние классы. Это закрывает H1 на уровне статуса: cc — не «недостающая цифра», а КЛАССОВЫЙ параметр; вопрос смещается от «сколько потребляется» к «кто потребляет».
**Честные границы:** приросты ≠ рентные потоки; домен — Норвегия; для средних классов INSUFFICIENT_DATA.

## T-D2 η-drift по Knoll et al. 2017 — DERIVED
**Якоря (уточнение T-F5):** доля земли в стоимости жилья США: ~20% (начало XX в.) → ~40% (2010-е), «roughly doubled»; >80% роста цен 1950–2012 = земля.
**Развёртка:** R_land = κ·s_land(t)·w·Y: 0.74% Y → 1.48% Y (×2.00); годовой дрейф доли ренты в Y = 0.63%/год при стабильных κ=30.1% и w=12.3%.
**Вывод:** H2 подтверждена как метод: спор о ВЕЛИЧИНЕ ренты (1.5–33%) — спор о D, а спор о СКОРОСТИ ренты — измерим рядом s_land(t) (Davis–Heathcote 2007 / Knoll 2017, публичные данные, 14 стран, 1870–2012). Следующий шаг — полная серия по странам, а не две точки.

## T-D3 DSR как η-потолок — DERIVED
**Якоря:** FRED TDSP Q1 2026 = 11.16% располагаемого дохода (корпус); DPI/GDP США 0.68–0.74 (ASSUMED); модель E*/S* = 0.19.
**Развёртка:** η_ceiling = 7.6–8.3% Y — домохозяйственный D→R канал работает с запасом ×2.3–2.6 до канонической интенсивности изъятия; сектор — в глубоком режиме выживания, граница ε<r далека.
**Вывод:** петля на уровне домохозяйств США — не автоколебательная, устойчивость обеспечена с большим зазором; дестабилизатор не интенсивность, а класс записи (MERS +3.1–3.4%/год кредита = R→D конвертер). Процентная часть TDSP отдельно — INSUFFICIENT_DATA (нужен ряд DRSPI/процентной доли DSR).

## T-D4 Матрица «тип редкости × класс записи» — MODEL (типология корпуса)
```
ЗЕМЛЯ      тип A   сброс структурно невозможен (поток переживает любое правило)
ЛИЦЕНЗИЯ   тип B   сброс экзогенный (акт воли: DMA, PSR, отмена)
ПАТЕНТ     тип B   сброс эндогенный по расписанию (~20 лет; продление сделками: Rinvoq→2037)
ДОЛГ       гибрид  сброс только институциональный B(t); рыночный шок −45% не работает (T-F4)
ПЛАТФОРМА  гибрид  β=сконструированная правилом доля редкости; (1−β)=сетевые эффекты (тип A)
```
**Свип гибрида:** A* = 0.184 (β=0) → 0.180 (0.25) → 0.152 (0.5) → 0.082 (0.75) → 0 (β=1). Поток переживает снятие правила частично, убывает по β, полный коллапс только при β=1.
**Вывод:** матрица H3 построена и фальсифицируема по доменам; β платформ — измеряемая величина (кандидат: уход сделок при смене комиссии, +3.2/+4.4 п.п.). Предсказание: чем выше β, тем чувствительнее позиция к регуляторному акту; эмпирический тест — PSR/DMA-эпизоды против сетевых гигантов.

## Свод по дожиму
- **Главный сдвиг парадигмы:** cc — не глобальная константа, а КЛАССОВЫЙ параметр (T-D1). Цикл Debt↔Rent для верхних классов самоподдерживающимся является ПО ПОСТРОЕНИЮ (φ_top≈1 >> φ_min=0.300) — «условность» цикла относится к нижним слоям потока. Это соединяет Meade-ветку Lumo с ФГМП-гетерогенностью и даёт формулировку: **петля универсальна не по экономике, а по распределению**.
- η (T-D2, T-D3): скорость ренты измерима (0.63%/год дрейф доли), интенсивность домохозяйственного канала — с запасом ×2.3 до границы; оба параметра теперь имеют численные якоря вместо UNKNOWN.
- Матрица A/B×запись (T-D4) — готовый инструмент классификации любых новых доменов: два вопроса (откуда редкость? где сброс?) полностью определяют динамический класс.
- Статус корпуса: все машинные тесты 8 задач EXECUTED; UNKNOWN остались: процентная доля DSR, β платформ, распределительный срез земельной ренты, первичная клинопись, PSR-апелляция.
