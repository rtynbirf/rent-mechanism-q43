## 1. Постановка R20 — пять атакующих тестов

Кандидат на слом:

$$ \boxed{ R = \max\left(0,\; Y - Y^{cf}\right), \qquad R>0 \iff Y > Y^{cf} } $$

Гипотеза R19, подлежащая проверке: рента — особый тип изъятия, определяемый не получателем и не названием платежа, а величиной избыточного потока относительно контрфактического состояния.

| T1 | Множественность легитимных контрфактов | Даёт ли критерий однозначное R вообще? |
| T2 | Капитализация ренты в цену актива | Не съедает ли критерий сам себя через самореференцию? |
| T3 | Налог / рента / нормальный доход | Различимы ли структурой, без институтов? |

## 2. T1 — МНОЖЕСТВЕННОСТЬ КОНТРФАКТОВ: критерий амбивалентен

### 2.1 Песочница (MODEL)

Один и тот же поток Y=100 (монопольное извлечение, носитель не меняется). Пять равно-легитимных контрфактов из стандартной теории:

| Контрфакт | Y^cf | Измеренная R |
|---|---|---|
| Цена свободной конкуренции | 80 | 20 |
| Лучшая альтернативная база (next best use) | 60 | **40** |
| Альтернатива держателя (reservation) | 95 | 5 |
| Исторический уровень | 70 | 30 |
| Якорь капитализированной рыночной цены | 100 | **0** |

**Разброс R ∈ [0, 40] на одном и том же потоке.** Критерий без правила выбора контрфакта не идентифицирует величину — он умножает сущности.

### 2.2 Вердикт T1

```
УТВЕРЖДЕНИЕ «формула R=Y−Y^cf самодостаточна»  → REJECTED
   (5 легитимных контрфактов → 5 разных рент: 0, 5, 20, 30, 40)
СЛЕДСТВИЕ: инвариант, если он есть, лежит не в формуле,
           а в ПРАВИЛЕ ВЫБОРА контрфакта (T5)
```

## 3. T2 — КАПИТАЛИЗАЦИОННАЯ ЦИРКУЛЯРНОСТЬ: брейкер

### 3.1 Конструкция

Носитель даёт поток Y=100 неограниченно (извлечение не падает). Нормальная отдача N_true=30 = r·K_repro при r=0.07; истинная рента R_true=70.

**Якорь A — воспроизводственная стоимость:** Y^cf = r·K_repro = 30 → R_изм = 70 = R_true. ✓

**Якорь B — рыночная цена актива:** актив торгуется и капитализирует измеренную ренту: A_t = A_{t−1} + R_изм,t; измерение R_изм,t = Y − r·A_{t−1}.

### 3.2 Песочница (MODEL) — динамическое затухание

| t | A_t (цена актива) | r·A (якорь-«норма») | R_изм |
|---|---|---|---|
| 0 | 428.57 | 30.00 | **70.00** |
| 1 | 498.57 | 34.90 | 65.10 |
| 2 | 563.67 | 39.46 | 60.54 |
| … | … | … | … |
| 57 | 1412.59 | 98.88 | 1.12 |
| 59 | 1414.75 | 99.03 | **0.97** |

Цена актива сходится к A* = Y/r = 1428.57 — современной стоимости **всего** потока. Измеренная рента **затухает к нулю**, хотя фактическое извлечение Y=100 продолжается без изменений.

**Тождества проверены точно:**
- якорь воспроизводства даёт R = 70 = R_true (exact);
- статичный рыночный якорь даёт R = Y − r·(R_true/r) = 30 = N_true — **измеритель переворачивается**: рента и норма меняются местами.

### 3.3 Веб-верификация (WEB-SUPPORTED)

- **MDPI / Füss et al. 2021 «Determining Land Values from Residential Rents»:** стоимость земли определяется ИЗ рент через капитализацию — стандартное направление вычисления (рента → цена), т.е. петля A=R/r — институциональная практика, а не артефакт модели.
- **Appraisal Institute / Sevelka (ground leases):** оценка = NOI + cap rate + реверсия — та же капитализация потока в стоимость.
- **NCUA 2025 (taxi medallion lending):** «медальон — приносящий доход актив; такие активы оцениваются через чистый операционный доход» — входной билет капитализирует ренту в цену.
- **DC CFO 2011:** «ценовая конкуренция за существующие медальоны **стирает экономическую ренту**» [для покупателя] — прямое эмпирическое описание брейкера: после покупки якорь = цена покупки, и измеренная рента покупателя ≈ 0 при продолжающемся извлечении лицензионным механизмом.

### 3.4 Вердикт T2

```
УТВЕРЖДЕНИЕ «критерий R=Y−Y^cf инвариантен к якорю»  → REJECTED (BREAKER)
ФАКТ (MODEL): при эндогенном рыночном якоре измеренная рента
   затухает 70 → 0.97 (→0) при неизменном извлечении 100.
ФАКТ (MODEL): два легитимных якоря дают комплементарные расщепления
   (R,N)=(70,30) и (30,70) одного и того же потока.
СЛЕДСТВИЕ: критерий НЕ самопроверяем; якорь должен быть
   ЭКЗОГЕНЕН циклу капитализации (см. T5).
```

## 4. T3 — КЛАССИФИКАЦИЯ БЕЗ ИНСТИТУТОВ: структура не отделяет налог от ренты

### 4.1 Песочница (MODEL)

Один носитель Q: Y=100, N_true=30, R_true=70. Три изъятия одной структуры Q→Y→F_i→K_i→Q′:

| Изъятие X | X ≤ R_true? | Вердикт структуры |
|---|---|---|
| Нормальная прибыль 30 | да | C holds: изъятие покрывается излишком |
| Налог 25 | да | C holds: структурно **неотличим** от ренты 25 |
| Налог 90 | **нет** | C FAILS: проедает нормальную отдачу → деградация носителя (режимы B/C из R15) |

**Наблюдение:** структура различает только СОВМЕСТИМОСТЬ ИЗЪЯТИЯ С ПРОДОЛЖЕНИЕМ (X vs R_true). Налог 25 и рента 25 при одинаковой величине неразличимы никаким структурным тестом — различие лежит в свойствах оператора F (compulsory/unrequited против claim-based), которые находятся ВНЕ ядра цикла.

### 4.2 Веб-верификация (WEB-SUPPORTED)

- **OECD (Classifying and collecting revenue data):** налог = платёж обязательный (compulsory) + безвозмездный (unrequited, sans contrepartie) + в пользу государства. Добровольные платежи налогами не классифицируются.
- **Еврокомиссия (Non-Tax Revenue in the EU):** та же формула — «compulsory and unrequited, not paid as direct compensation for a specific good».
- **OECD-IL / Daubanes 2014 «Taxing the Rent of Non-Renewable Resource Sectors»:** налогообложение ресурсной ренты — отдельная категория с собственной теорией: налог МОЖЕТ быть прицелен именно на ренту как базу.

### 4.3 Вердикт T3 — закрытие вопроса R19

```
Гипотеза R19 «K_T = K_R»  → ЗАКРЫТА ОТРИЦАТЕЛЬНО В ПОСТАВКЕ «одинаковый оператор»:
   но найдено сильнее — налог и рента имеют ОБЩУЮ структуру цикла и ОБЩЕЕ условие
   продолжения C, а различаются СВОЙСТВАМИ ОПЕРАТОРА ИЗЪЯТИЯ F:
   F_T = compulsory/unrequited (OECD), F_R = claim на surplus.
НОВОЕ СТРУКТУРНОЕ ОТКРЫТИЕ — граница совместимости:
   X ≤ R_true  →  изъятие совместимо с продолжением цикла
   X > R_true  →  изъятие проедает норму → деградация носителя (R15-B/C)
   Это фискальная теорема: УСТОЙЧИВОЕ ИЗЪЯТИЕ ОГРАНИЧЕНО ИСТИННОЙ РЕНТОЙ НОСИТЕЛЯ.
```

## 5. T4 — КВАЗИ-РЕНТА: конфликт глубины маржи

### 5.1 Песочница (MODEL)

Оборудование фиксированного предложения: Y=100; избежимые издержки 40; невозвратные постоянные 50.

| Маржа | Что избегается | R |
|---|---|---|
| Краткосрочная (fixed supply) | только избежимые 40 | **60** |
| Долгосрочная (full cost) | всё: 90 | **10** |

**Отношение 6:1 на одном и том же потоке.** Критерий без правила выбора маржи конфундирует квази-ренту фиксированного предложения со scarcity-рентой.

### 5.2 Веб-верификация (WEB-SUPPORTED)

- **Маршалл, Principles (Guillebaud/UCLA, cited 57):** квази-рента — «scarcity value специализированного оборудования, квалифицированного труда и т.п., предложение которых можно считать фиксированным в кратком периоде» — фиксированность предложения, а не природа вещи, задаёт ренту.
- **Маршалл (Principles, кн.5):** квази-рента — «unnecessary profit», «no part of cost» для кратких периодов.
- **Маршалл 1893 «On Rent»:** рента земли отличается от чистых доходов других факторов «in degree rather than in kind» — граница рента/не-рента сама является маржинальной, градуированной.

### 5.3 Вердикт T4

```
УТВЕРЖДЕНИЕ «критерий даёт одну ренту одного потока»  → REJECTED
   (60 vs 10 при смене глубины маржи)
СЛЕДСТВИЕ: правило выбора контрфакта обязано фиксировать МАРЖУ РЕШЕНИЯ
   (какое решение принимает агент: войти/остаться/воспроизвести носитель)
```

## 6. T5 — ЯКОРЬ СВОБОДНОГО ВХОДА: правило, спасающее критерий

### 6.1 Песочница (MODEL)

Два рынка с одинаковым спросом: вход свободен против входа, заблокированного лицензией. Вход расширяется, пока profit>0.

| Рынок | n (равновесие) | y | profit (= R) |
|---|---|---|---|
| Свободный вход | сходится к n* = 15.0 | 49.8–50.1 = N_entry | **→ 0** (−0.19 в хвосте) |
| Лицензия n_max=8 | зажата на 8 | 120 | **70 — устойчиво** |

Правило-якорь: **Y^cf = отдача на марже свободного входа / воспроизводства носителя**. Тогда:
- R>0 ⇔ вход заблокирован — критерий становится ФАЛЬСИФИЦИРУЕМЫМ предиктором;
- предсказание согласовано с R11-A (Гордон: открытый доступ → рассеяние → R=0) — два независимых прогона песочницы сошлись.

### 6.2 Веб-верификация (WEB-SUPPORTED)

- **Баумол, «Contestable Markets: An Uprising in the Theory of Industry Structure» (JSTOR 1983, cited 373; World Bank 1991, cited 138):** совершенная оспариваемость исключает сверхприбыли «посредством нулевой стоимости входа»; устойчивые цены = нулевая прибыль. Свободный вход — нулевая измеренная рента.
- **Рикардо (закон ренты):** «рента равна экономическому преимуществу использования высокопродуктивных участков земли относительно маржинальной земли» — канонический якорь контрфакта = СВОБОДНАЯ маржа (не присвоенная, не капитализированная).
- **Wikipedia/contestable market (сводка):** признаки — отсутствие барьеров входа/выхода и невозвратных издержек.

### 6.3 Вердикт T5

```
УТВЕРЖДЕНИЕ «правила выбора Y^cf не существует в структуре»  → REJECTED
ПРАВИЛО НАЙДЕНО (MODEL + WEB):
   Y^cf = отдача на марже свободного входа / воспроизводства носителя
   (anchor = free-entry / reproduction margin)
   тогда R>0 ⇔ вход в воспроизводство носителя заблокирован
СХОДЖЕНИЕ: Баумол (contestability) + Рикардо (маржинальная земля)
           + Гордон (R11-A, рассеяние в открытом доступе)
СТРУКТУРНОЕ ВОССОЕДИНЕНИЕ: источник ренты R0 (scarcity/exclusivity)
   и измеритель R20 (контрфакт) — ОДИН ФАКТ с двух сторон цикла:
   блокировка входа = эксклюзивность; измеренная рента = поток над маржой входа
```

**Итог:** контрфактический критерий ренты **сломан как самодостаточный**, но **спасён как якорный**:

$$ \boxed{ R > 0 \iff \big(\text{вход в воспроизводство носителя заблокирован}\big) \ \land\ \big(Y > \text{отдача на марже свободного входа}\big) } $$

$$ \boxed{ R = \max\left(0,\; Y - \text{return}^{\,free-entry\ margin}\right) } $$

## 9. Обновлённая форма механизма после R20

```
МИНИМАЛЬНЫЙ ЦИКЛ (без времени/пространства, P∈E, R∈функция):
   B → Y → F → K → B,   при R(Y)>0

ИЗМЕРИТЕЛЬ РЕНТЫ (якорный, фальсифицируемый):
   R = max(0, Y − return^free-entry margin)
   R > 0  ⇔  вход в воспроизводство носителя заблокирован

УСЛОВИЕ ПРОДОЛЖЕНИЯ C (в терминах изъятия):
   X ≤ R_true  → цикл совместим с изъятием
   X > R_true  → проедание нормы → режимы деградации/коллапса (R15-B/C)

РАЗЛИЧИЯ ИЗВЛЕЧЕНИЙ (закрытие R19):
   структура (Q→Y→F→K→Q′~Q) и условие C — ОБЩИЕ для налога, ренты, нормы;
   налог/рента различаются свойствами оператора F:
      F_T: compulsory + unrequited + recipient=Gov   (OECD)
      F_R: claim на surplus над маржей               (Рикардо/Баумол)
   фискальная теорема: устойчивое изъятие ограничено истинной рентой носителя

КАТЕГОРИЧЕСКОЕ ПРАВИЛО (укреплено R20):
   измеритель ренты обязан быть ЭКЗОГЕНЕН циклу капитализации;
   эндогенный (рыночный) якорь поглощает ренту в «норму» и слепнет
```

## 10. CAVEATS — границы честности

1. **T2 — модельная демонстрация возможности, не эмпирическая оценка.** Динамика A_t=A_{t−1}+R_изм — стилизация процесса капитализации; реальные рынки не капитализируют поток до полного A*=Y/r мгновенно (барьеры информации, риска, ликвидности). Направление и знак эффекта подтверждены практикой оценки (NOI/cap rate) и кейсами медальонов, но скорость затухания измеренной ренты в данных не калибровалась.
2. **Пять контрфактов T1 — не исчерпывающий список.** Существуют иные легитимные якоря (социальная ставка дисконтирования, регулируемая норма, WACC по секторам); вывод «критерий амбивалентен без правила» устойчив к расширению списка, но конкретный разброс [0,40] зависит от набора.
3. **Граница X≤R_true получена в модели фиксированного Y.** При эндогенном Y (изъятие подавляет генерацию — кривая Лаффера) граница смещается внутрь; не протестировано.
4. **Маржа свободного входа не всегда наблюдаема.** Если входной билет сам капитализирован (лицензия продаётся по цене capitalized rent), «свободная маржа» исчезает как наблюдаемая величина — это главный шов, передаваемый в R21.
5. **Баумол-якорь чувствителен к sunk costs:** при невозвратных издержках входа contestability ослабевает; правило требует уточнения для секторов с высокой необратимостью инвестиций.
6. **Лестница L1/L2/L3:** всё — L2-кандидаты; L3 не заявляется; A/B/Ablation в живых режимах не проводились.

## 12. R21 — автопорождённая следующая задача

Шов передан из CAVEAT-4. Входной билет сам стал активом:

$$ \boxed{ \text{ЦЕНА ВХОДА} = PV(\text{будущей ренты}) \;\Rightarrow\; \text{свободная маржа исчезает как наблюдение} } $$

Медальон: лицензионный механизм продолжает извлекать ренту из потока, но покупатель, заплатив капитализированную цену, зарабатывает лишь «норму» на вложенный капитал (DC CFO: конкуренция за медальоны стирает экономическую ренту — для покупателя). Куда ушла рента? К тому, кто РАЗДАВАЛ/ПЕРВЫМ закрепил позиции.

**R21 — локализовать точку захвата ренты в капитализированных системах входа:**

```
T1: для медальонной модели проверить тождество:
    рента потока = доход первичного грантователя + процентный доход
    держателя капитализированной цены − риск-премия;
    где именно сидит capture: в F потока или в разовой цене входа?
T2: проверить якорь воспроизводства против рыночного на событии
    обвала цен медальонов 2013–2018: обе оценки ренты совпадают только
    ПОСЛЕ коллапса — значит, pre-collapse измерение рыночным якорем
    систематически занижало ренту. Оценить величину занижения.
T3: обобщить: какие ещё входные билеты капитализированы
    (частоты спектра, квоты вылова ITQ, франшизы, слоты аэропортов,
    банковские лицензии) и как для них строить экзогенный якорь
    воспроизводства.
```

**Главный вопрос R21:** *когда вход капитализирован, измеритель ренты должен сместиться с потока на момент раздачи позиций — остаётся ли критерий R=Y−Y^cf вообще применимым, или рента фиксируется только в акте первичного закрепления?*
