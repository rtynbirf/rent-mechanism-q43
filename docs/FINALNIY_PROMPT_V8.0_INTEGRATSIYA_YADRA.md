## §1. Ядро Q43 v2

**Состояние:**

```
Q43 = (S, Ah, X, F, B, C, N, G, W, P, M, I)
```

| Элемент | Содержание | Статус |
|---|---|---|
| S, Ah, X, F, B, C, T | онтология пользователя (носитель/акт/исключение/поток/выгода/капитал/передача) | canon, R42–R43 |
| N | нормативный акт с силой (первая опора потока) | OBSERVED (Д1) |
| G | реестр носителей → **G\*** = функциональный реестр (любой носитель знания «кто держит»: госреестр, карта туфов, синдикат, общинная память) | OBSERVED (R44-a) |
| W | политическое воспроизведение акта → **W_lat** = латентная опция государства | OBSERVED (R46-c: дисконт в ценах) |
| P | слой капитализации (место как актив/залог) | OBSERVED (трёхслойность) |
| M | изготовление места для нового носителя ≈ бесплатно (grandfathering/ваучеры/пороговые цены) | OBSERVED (Д2) |
| I | информация как оператор | SUPPORTING (R39) |

**Оператор:** `Φ42(Q_t; R_t, N_t, G_t, W_t)`. **Цена места:**

```
V_t = Σ_s E[R_s | модель шока] / (1+r)^s × Prob(survival)
```

**Иерархия необходимости (машинно, R46-e M3, 14 кейсов):**

- **MIN-SET = {K1, K2}** — предел множества носителей + исполняемое исключение. Строго необходимы в любой форме (государственной или частной). Все 11 оцениваемых выживших случаев с рентой > 0 имеют K1+K2; 0 исключений.
- **G\*** — функционально заменим (частный носитель функции реестра; цена замены = рост издержек принуждения).
- **W_lat** — латентная опция государства; обязательна только при политически контингентном акте; наблюдаема в ценах как дисконт экспроприации (закон L5).
- **K3/K4** — диагностические: их отсутствие совместимо с рентой, но убивает наблюдаемую легальную цену места (номенклатура: K3=0, K4=0, рента живёт; обычное право: цена дисконтирована).

**Каналы воспроизводства (машинно, R44-f T3):** монолитный K опровергнут.

```
K = {K_f (финансирование), K_w (защита нормы), K_s (спонсирование редкости), K_t (передача)}
```

Отказы попарно различны: K_f=0 → поток жив, цена 0 (KO6); K_w=0 → поток −90% (KO1); K_s=0 → распад редкости, поток ×0.003 (R33-A3, De Beers); K_t=0 → механизм кончается (C1/C5).

## §2. Три слоя, раздельно наблюдаемы

- **F = поток** (K1+K6→G\*+K2): сбор держателя минус издержки исключения; исток — приведение нормы в исполнение, не физический факт.
- **P = капитализация** (K3+K4): место как актив; слой распадается без потока не мгновенно (NYC 2020–22: F живёт при разрушенном P).
- **W = воспроизводство** (K5+обновление K1): политическая защита акта и предела.

Раздельная наблюдаемость: РФ 1992–94 (F без P), Лондон (барьер без P и места-капитала), NYC 2020–22 (F частично живёт при разрушенном P). Слои — наблюдение, не проекция (R42, CHK4: машинный запрет формального словаря в фазе наблюдения, 0 вкраплений).

## §3. Шесть законов (все машинно проверены)

### L1. Закон серого зеркала (R47-c; r48_results.json, PASS 5/5)
При сильных K1+K2 и ренте > 0 цена места существует **в каком-то режиме** — легальном или теневом; никогда нигде не ноль. Без K1 цены нет ни легально, ни в тени (джитни 1915, Лондон). Диагностическое правило «нет цены ⟹ нет ренты» валидно только в легальном режиме при известном K1; в теневых режимах рента диагностируется по потоку (взносы/дань/тариф). К3/K4 переносятся в серые двойники при закрытии легального канала.
Числа: СССР — «должность секретаря обкома стоила полмиллиона рублей» ≈ 178 окладов (2 800 руб/мес) ≈ капитализация ~14.9 лет дохода (мультипликаторный класс, не «подарок»); Сицилия — €457/мес торговец, €578 отели, >€2 000 стройка, ~160 тыс. фирм, >€10 млрд/год, Палермо 80% платят; Дар-эс-Салам — взносы синдикату > 0 при «близком к совершенной конкуренции» рынке 2002.

### L2. Закон доноров (R45; r46e M2, PASS)
При R_t < MAINT+APPARATUS(+DEBT_SERVICE) класс механизма определяется **позицией донора**. Цена спасения строго упорядочена:

```
D0 = $0 (правило) < D4 = $350M (кредитор) < D2 ≥ $471M (налогоплательщик) < D1 = $2.9B (резервы = терминально)
```

- D0 — отмена самой обязанности: слотовый waiver COVID (FAA 03.2020, DfT-закон 26.02.2021); рента не прерывалась ни на день; класс сохранён; $52.3M/пара (2008) → рекорд $75M/пара (08.2025).
- D4 — прощение кредитора: Marblegate $70M (09.2020), кумулятивные списания $350M к 01.2023, >$471M финал; класс сохранён, P перепрайсировано до 0.75×; не масштабируется (holdout-кредиторы, «сотни без помощи»).
- D2 — деньги налогоплательщика: MRP+ (гранты $65.7M + резерв $50M + открытая гарантия; 2 034 владельца / 2 367 медальонов; платёж ≤ $1 234/мес при farebox ~$7 080/мес = 15–17% ренты); **класс меняется** → государственно-опекаемый. Кавет: >$471M включает D4-списания; строго городские деньги $115.7M.
- D1 — собственные резервы: De Beers — запас $2 млрд (12.2024), impairment $2.9 млрд (02.2025), третий даунгрейд $4.1B→$2.3B (02.2026), продажа ~$1B (07.2026), закрытие крупнейшего рудника; при реальном шоке заместителя резервы канал цены не восстанавливают → смерть механизма.
- D3 — донор = держатель = государство (номенклатура РФ): непрерывность, нет события перезапуска, ~60% элит-преемственность.

### L3. Закон паразитарности (R44-d; r46e M3)
Класс взаимодействия слоя держателей с источником определяет **тип капа**, не желание держателей: ресурсный кап → мутуализм или дренаж (исход решает TAC-наука: NZ хоки — стоки ×2 с 2001, 82% выше soft limit, Хаураки −25% добровольно; dairy $2.4 млрд/год при стабильном источнике — дренаж); лицензионный кап → дренаж в стационаре + ФЛИП под шок заместителя (NYC: FHV-кап 08.2018 ради цен медальонов при поездках 463.7k→336.7k/день 2010→16). Класс НЕКРО (слой убивает источник) **пуст**: не найдено ни одного случая.

### L4. FR6-условный: амплитуда P против F зависит от типа шока (R44-e KO6 → R46-e M1, PASS)
- РЕЖИМНЫЙ шок (Uber, кредитный оверхэнг): перекройка и потока, и выживания → |ΔP| > |ΔF|. NYC: ΔV = −0.89…−0.946 против F ≈ −0.4…−0.5 (машинно: сдвиг потока ×0.726 даёт −0.274; полный эффект −0.984 с репрайсингом выживания ×0.152; долговой оверхэнг: OAG 20.02.2020 «цена не обеспечивалась доходом», 66% форклозов, >950 банкротств).
- ПОВТОРЯЮЩИЙСЯ шок (засуха/паводок) запрайсен заранее: |ΔP| < |ΔF|. MDB: |ΔV| = 0.14 < |ΔF_spot| = 2.35 (спот +140%/−95%, реализованная просадка двигает V ровно на 0 при неизменных вероятностях состояний).
- KO6-«FAIL» из r44e снят как категориальная ошибка (не было условия на тип шока).
- Конфликт метрики дна NYC ($110k vs $80k vs плато $70–75k) РЕШЁН (R47-d, первичный TLC workbook): различие = период агрегации, не состав сделок; вывод устойчив к выбору метрики.

### L5. Дисконт W_lat: дисконт ≈ p·(1−c)·V (R46-c, HIGH)
Латентная опция государства наблюдаема в ценах. ЮКОС: Yuganskneftegaz куплен за $9.35 млрд (12.2004) против независимых оценок $14.7–22 млрд → −36…−69% (−83% к оценке $56 млрд); **до активации** дисконта не было (акции +191% в 2001, +81.5% в 2002). Зимбабве: c≈0 → исчезновение рынка и залога (табак 2008 = 21% уровня 2001). Венесуэла: опция платная (ICSID, Conoco $8–9 млрд). США: c≈1 → дисконт пренебрежим. Индия-2G: рента реальна (вторичный рынок 6× цены лицензии; CAG ₹1 760 млрд), но защита не сработала — отмену произвёл сам верховный суд (02.02.2012, 122 лицензии) при дискредитированном лобби.

### L6. FLIP-пара: два зеркальных эксперимента
- **NYC** (слой против заместителя при шоке): кап не снят ни на день; W-акт (MRP+) перераспределил бремя и сохранил класс; рынок передач жив (695→924→678→1 003, 2021–24), P ≈ −0.9.
- **Дублин-2000** (снятие слоя до шока): S.I. 367/2000 (после Humphrey [2000] IEHC 149) снял количественные ограничения; плита IR£80–100k рассеялась входом; парк 2 722 → 8 609 (2002) → 11 630 (2003) = ×4.3; ожидание >30 мин после полуночи 43% (1997) → 6.2% (2001); сервиса это не ухудшило; компенсаций как права нет; численный кап не вернулся (ре-каптура 2010 — S.I. 248/2010).
- Вывод: снятие слоя рассеивает ренту места **через вход**, не через сервис; спасение = дискреционный политический донор (сработал только в NYC; Бостон −95% без спасения, дно одинаковое).

## §4. Цикловая формула пользователя — вердикт (R44-f, машинно)

Схема: `Q_t → A → B_t → R_t → K → Q_{t+1}`; A = статусно-доходный оператор; K = оператор участия в воспроизводстве.

- **Скелет ПРИНЯТ**: B регенерирует (R32-C6), R реляционен (R20), вход без P_entry (R30/R42).
- **Сильная форма инварианта ОПРОВЕРГНУТА**: per-cycle форма (∀t: R_t>0) — NYC 2020 DORMANT-циклы при живой Q; домен входа шире R_t (T2: без донора смерть на t=6, с донором выживание → вход ∈ {R_t, резервы, внешний донор}); «связанная выгода» без явного домена нефальсифицируема; T4: без R-условия схема неотличима от производственного цикла (Гордон, R≡0).
- **Патч принят как инвариант программы:**

```
I_K″: ∃Q, ∃t*: R_{t*} > 0
  ∧ Q_{t+1} = Φ42(Q_t; K_f, K_w, K_s, K_t)
  ∧ вход K ∈ {R_t, резервы, внешний донор}
  ∧ множество носителей замкнуто (N + G + C оперативны)
  ∧ выживание без R_t-взноса — только через резервы/донора   [фальсифицируемо: N9]
```

- Дизъюнкция оператора A не замкнута («…» в формулировке); наблюдение даёт замкнутый набор: N (акт) + G (реестр) + C (принуждение).
